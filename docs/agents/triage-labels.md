# Triage 标签

各个 skill 使用五个规范的 triage 角色来表述。本文件把这些角色映射到本仓库 issue 载体中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库载体中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整定义,可由 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当某个 skill 提到某个角色时(例如"套用 AFK-ready 这个 triage 标签"),使用本表中对应的标签字符串。
